A dual-interface MERN stack platform where recruiters post jobs and students apply in real time. Built with JWT + httpOnly cookies for auth, role-based access control (Student/Recruiter), and compound MongoDB indexes that cut API response latency by ~40%.

#### 🤖 [Smart Email Assistant](https://github.com/dynamicshreyashh/smart-email-assistant)
> Java · Spring Boot · Google Gemini AI · Chrome Extension

A backend service that uses Google Gemini to analyze email context and generate smart replies. Paired with a custom Chrome Extension that injects a "Smart Reply" button directly into Gmail using `MutationObserver`. The REST API keeps AI logic decoupled from the client and API keys protected.
